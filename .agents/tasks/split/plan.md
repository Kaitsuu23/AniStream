# Implementation Plan — AniStream Backend/Frontend Split

**Goal:** Split the monolithic Express app into a pure-API backend (VPS) and a pure-static
frontend (Vercel). No new dependencies are introduced; dotenv is NOT added.

---

## Key findings from codebase exploration

- `server.js` — serves HTML pages via `sendMinified()` with `%%CF_WORKER_URL%%` injection AND
  serves the API. Both roles must be separated.
- `routes/api.js` — untouched. All API logic stays here.
- `scraper/anichin.js` — untouched. Returns ALL poster/image URLs as `/api/proxy/image?url=...`
  (relative paths). These must be prefixed with `window.API_BASE_URL` on the frontend whenever
  they become an `<img src>` or a `fetch()` target.
- `public/js/app.js` — `fetchAPI()` uses `const API = '/api'` correctly, BUT `initPopularWidget()`
  calls `fetch('/api/popular')` directly (hardcoded relative URL, bypasses the `API` const).
  All card images come from `item.poster` which may be `/api/proxy/image?...`.
- `public/js/player.js` — reads `window.__CF_WORKER_URL__` (injected by server at runtime).
  Calls `fetch('/api/episode/...')` and `fetch('/api/anime/...')` directly (no `API` const).
  `proxyEmbed()` and `proxyStream()` fall back to `/api/proxy/embed?...` and
  `/api/proxy/stream?...` when CF_WORKER_URL is absent — both relative.
- `public/js/router.js` — 7 additional raw `fetch('/api/...')` calls:
  - `fetch('/api/home')` (twice in `renderListPage`, once in `renderAZPage`, once in
    `renderGenresPage`)
  - `fetch('/api/schedule')` in `renderSchedulePage`
  - `fetch(\`/api/genres/${...}\`)` in `renderGenresPage`
  - `fetch(\`/api/az/${...}\`)` in `renderAZPage`
  - `fetch(\`${apiPath}${sep}page=${page}\`)` in `renderListPage` where `apiPath` is passed from
    HTML inline scripts as e.g. `'/api/ongoing'`
- `episode.html` — only HTML file with `%%CF_WORKER_URL%%` injection and `player.js` script.
- All 14 HTML files load `app.js` and `router.js` but NOT `player.js` (only `episode.html` does).
- `package.json` — dependencies: express, cors, axios, cheerio, html-minifier-terser,
  serverless-http. `html-minifier-terser` must be removed.
- `.env` file does not exist in the repo (gitignored). Instructions create it separately per env.

---

## Cross-origin correctness strategy

**Image proxy URLs:** `scraper/anichin.js` cannot be modified. It returns `/api/proxy/image?url=...`
for every poster. These strings appear in card HTML built by `buildCard()` in `app.js` and in
`schedule`, `genres`, `az`, and list pages built inline in `router.js`. The cleanest zero-
duplication fix: add an `apiUrl(u)` helper in `app.js` (before any other code) that prefixes
any string starting with `/api` with `window.API_BASE_URL`. Apply it in:
- `buildCard()` — the `poster` value passed to `<img src>` and card `onclick` URLs already go
  through `/episode/` or `/anime/` (those are frontend routes, not API — no prefix needed there).
  Only `poster` needs `apiUrl()`.
- `buildHero()` — `item.poster` used as `<img src>`.
- `initPopularWidget()` — `item.poster` in `<img src>`.
- `router.js` inline HTML templates — schedule page card `a.poster`, genres page card posters,
  az page card posters (all go through `buildCard()` which handles them after the fix),
  EXCEPT schedule builds its own card HTML directly — poster must use `apiUrl()` there.

**Direct `/api` fetch calls:** All raw `fetch('/api/...')` and template-literal fetch calls must
go through `apiUrl()`. Specifically: `initPopularWidget()` in `app.js`,
`fetch('/api/episode/...')` and `fetch('/api/anime/...')` in `player.js`, and all fetch calls
in `router.js`.

**Approach:** `apiUrl(u)` is defined once in `app.js` (loaded on every page). `player.js` uses
its own `const API_BASE = window.API_BASE_URL || ''` since it may load before or after
`app.js`. `router.js` uses `apiUrl()` (already defined by `app.js` which loads first).

const fs=require('fs');
const dir='public';
fs.readdirSync(dir).filter(f=>f.endsWith('.html')).forEach(f=>{
  const c=fs.readFileSync(dir+'/'+f,'utf8');
  const ci=c.indexOf('config.js');
  const ai=c.indexOf('app.js');
  const ok = ci!==-1 && ci<ai;
  console.log(f+':', ok?'OK':'FAIL - config.js not before app.js');
});
"
